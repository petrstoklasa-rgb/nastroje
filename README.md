# nastroje

Galerie mých mikronástrojů. Každý nástroj je jeden HTML soubor ve vlastní složce a běží jen v prohlížeči.

Veřejná adresa (GitHub Pages): https://petrstoklasa-rgb.github.io/nastroje/

| Nástroj | Složka | Popis |
|---|---|---|
| Kalkulačka složeného úroku | `kalkulacka-uroku/` | Vývoj vkladu za 10 let při 5, 12 a 20 % ročně, měsíční úročení |

Jak přidat nástroj: viz `CLAUDE.md`. Zadání nástrojů vznikají podle šablony `2-Areas/AI-system/prompty/sablona-zadani-nastroje.md` (Google Disk).
